# GLYPH ASCII Studio

把图片转成 ASCII 字符画的本地工作台。除基础的裁剪、色调与导出外，内置一个
**字形标定台**：加载本地等宽字体后，按字体的真实覆盖率建立“明暗 → 字符”映射。

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

## 字形标定台

- **加载字体**：默认自动加载内置的 DejaVu Sans Mono（WOFF2，随包分发，许可证见
  `public/fonts/DejaVuSansMono.LICENSE.txt`）。也可选择本地 TTF / OTF / WOFF /
  WOFF2 / TTC。
- **测量**：以当前字号与字符框尺寸把每个候选字符绘制到画布，读取其 alpha 覆盖率
  （平均墨色）与 3 × 3 的局部墨色分布。测量会等待字体真正可渲染（比对字体
  metrics 与浏览器实测 advance），不会在回退字体上偷偷测量。
- **缺失字形**：字体未提供的字符（以及被浏览器回退替换的字符）会被剔除，列在
  “缺失字形不参与排序”，预设顺序同样会跳过它们。
- **两种选字倾向**：
  - *只看平均墨色*：只按覆盖率误差取字，等价于传统阶梯。
  - *兼顾局部结构*：在覆盖率误差很小的候选里，选择 3 × 3 局部结构与图像更接近的
    字形。细线图能看出结构倾向更贴合线条，渐变图上两者阶梯都很平滑。
  - 两种倾向的阶梯与“细线图 / 渐变图”对照会同时展示，取舍一目了然。
- **稳定选择**：所有排序都是确定性的；相同覆盖率的多个字符按声明顺序（再按码位）
  选择，不会随机跳变。
- **一起更新**：调整字号、字符框或候选字符后，标定数据、图像采样、字符预览与导出
  会一起重算；导出按钮在重新生成完成前保持禁用。
- **失败保留**：字体加载或测量失败时保留上一份可用字体与标定，并显示错误原因。
